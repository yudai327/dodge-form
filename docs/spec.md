# dodge-form 仕様書

## 概要

学校・スポーツチームのイベント向け参加回答＆配車管理システム。
Google Sheets をバックエンドとし、参加者の出欠・送迎希望を収集して管理者が配車割り当てを行う。

---

## アーキテクチャ

```
[ブラウザ]
  index.html   ← 参加者が回答（公開）
  admin.html   ← イベント作成・削除（管理者）
  view.html    ← 集計・配車管理（管理者）
       │
       │ fetch (GAS API)
       ▼
[Google Apps Script]
       │
       ▼
[Google Sheets]  ← 永続データストア
```

**技術スタック**

| 項目 | 内容 |
|---|---|
| フロントエンド | HTML5 / Vanilla JS (ES6+) / Tailwind CSS (CDN) |
| バックエンド | Google Apps Script (Web App) |
| データストア | Google Sheets |
| ビルドツール | なし（静的 HTML） |

## ページ仕様

### index.html — 参加回答フォーム

**目的:** 参加者が出欠・送迎希望を回答するための公開フォーム。

**URLパラメータ:**
- `?event=<イベント名>` — 対象イベントをドロップダウンで自動選択する

**初期表示処理:**
1. `getSheets` API を呼び出してシート一覧を取得
2. 以下の条件を**両方**満たすシートのみドロップダウンに表示
   - `【結果】` を含まない
   - 対応する `【結果】{シート名}` が存在しない（＝結果保存済み＝締め切り済み）
3. URL パラメータの `event` と一致するシートを選択状態にする
4. 取得中はセレクトと送信ボタンを無効化しローディング表示
5. 受付中のイベントが 0 件の場合「受付中のイベントはありません」を表示

**フォーム項目:**

| フィールド名 | 要素 | デフォルト | 必須 |
|---|---|---|---|
| 対象イベント | `<select>` (動的生成) | — | ○ |
| 学年 | `<select>` 1〜6年 | 1年 | — |
| 名前 | `<input type="text">` | — | ○ |
| 参加の可否 | Radio: 参加 / 不参加 | 参加 | — |
| 送迎の可否 | Radio: 可 / 不可 | 不可 | — |
| 送迎の空き人数 | `<input type="number">` min=0 | 0 | — |
| 乗り合わせの可否 | Radio: 可 / 不可 | 不可 | — |
| 乗り合わせの希望人数 | `<input type="number">` min=0 | 0 | — |
| 備考 | `<textarea>` rows=3 | — | — |

**送信処理:**
- POST ボディ（JSON）を GAS エンドポイントに送信（`mode: 'no-cors'`）
- 送信中はボタンをスピナー表示＋無効化
- 成功: アラート "送信が完了しました！" → ページリロード
- 失敗: アラート "送信エラー" → ボタン復元

**POST ボディ:**
```json
{
  "eventName": "string",
  "grade": "1年" | "2年" | "3年" | "4年" | "5年" | "6年",
  "name": "string",
  "attendance": "参加" | "不参加",
  "pickup": "可" | "不可",
  "pickupCount": "number (string型)",
  "carpool": "可" | "不可",
  "carpoolCount": "number (string型)",
  "note": "string"
}
```

### admin.html — 管理パネル

**目的:** イベントの作成・削除、招待URLの生成。パスワード保護。

**認証:** ページロード時にパスワードを prompt で確認。不一致なら index.html へリダイレクト。

**機能一覧:**

#### 1. イベント作成

- テキスト入力でイベント名を入力（例: `4月10日 練習試合`）
- 「新規シートを作成」ボタンで GAS にシート作成を依頼
- 成功後、招待URL（`index.html?event=<イベント名>`）を表示
- 「URLをコピーする」でクリップボードにコピー
- POST ボディ:
  ```json
  { "type": "createEvent", "eventName": "string" }
  ```

#### 2. 配車管理画面へのナビゲーション

- `view.html` へのリンク

#### 3. イベント一覧・削除

- `getSheets` API で全シートを取得して一覧表示（`【結果】` 含む全シート）
- 各イベントに削除ボタン
- 削除前に confirm ダイアログで確認
- POST ボディ:
  ```json
  { "type": "deleteEvent", "eventName": "string" }
  ```
- 削除後、一覧を自動更新

### view.html — 配車管理（集計）画面

**目的:** 参加者データの閲覧・編集と配車割り当ての記録、結果シートの作成。

**認証:** admin.html と同じパスワード認証。

**初期表示処理:**
1. `getSheets` API でシート一覧を取得してドロップダウンに表示
2. 取得中はセレクトと読込ボタンを無効化

**操作フロー:**
1. ドロップダウンでイベントを選択
2. 「読込」ボタンでそのシートのデータを取得
3. テーブルで内容を確認・編集
4. 「【結果】を作成・保存」で保存

**テーブルカラム（行データのインデックス対応）:**

| カラム | index | 表示名 | 編集可否 |
|---|---|---|---|
| 学年 | 0 | 学年 | × |
| 名前 | 1 | 名前 | × |
| 参加可否 | 2 | 参加 | × |
| 送迎の可 | 3 | 自車(空き) | ○ チェックボックス |
| 送迎の空き人数 | 4 | — (3と合わせて表示) | × |
| 乗り合わせの可 | 5 | 他車(希望) | × |
| 乗り合わせの希望人数 | 6 | — (5と合わせて表示) | × |
| 配車メモ | 7 | 配車先を入力 | ○ テキスト入力 |
| 備考 | 8 | 備考 | ○ テキストエリア |

**行の表示ルール:**
- `row[2] === '参加'` → 通常表示
- `row[2] !== '参加'` → `bg-red-50 opacity-50`（赤背景・半透明）

**日付誤入力ガード:**
- `row[7]` / `row[8]` に `T` と `Z` を両方含む文字列（ISO 8601 日時形式）が入っている場合、空文字に置き換えて表示しない

**保存処理:**
- POST ボディ:
  ```json
  { "type": "updateData", "eventName": "string", "rows": [[...], ...] }
  ```
- GAS 側で `【結果】<イベント名>` という名前のシートを作成し、6列に絞って保存
- 成功メッセージ: `「【結果】<イベント名>」を6項目に絞って保存しました！`

## GAS API 仕様

**エンドポイント:**  
`https://script.google.com/macros/s/AKfycbwUiiynEDBvBNe5o7PrhMcCwFypBvrRosmuLaC3vJPM2KCpX6ZLMupBJwlH-SZIj8VO_w/exec`

すべての書き込みリクエストは `mode: 'no-cors'` で送信するため、レスポンスボディは取得不可。

### GET アクション

| アクション | リクエスト | レスポンス |
|---|---|---|
| getSheets | `?action=getSheets` | `["シート名1", "シート名2", ...]` |
| getData | `?action=getData&sheetName=<name>` | `{ "rows": [["1年", "太郎", ...], ...] }` |

### POST アクション

| type | ボディ | 内容 |
|---|---|---|
| createEvent | `{ type, eventName }` | 新規シート作成 |
| deleteEvent | `{ type, eventName }` | シート削除（不可逆） |
| updateData | `{ type, eventName, rows }` | データ更新＋結果シート作成 |

## データモデル

### 参加者レコード（1行）

| index | フィールド | 型 | 値の例 |
|---|---|---|---|
| 0 | 学年 | string | `"3年"` |
| 1 | 名前 | string | `"山田太郎"` |
| 2 | 参加可否 | string | `"参加"` / `"不参加"` |
| 3 | 送迎の可 | string | `"可"` / `"不可"` |
| 4 | 送迎の空き人数 | string | `"2"` |
| 5 | 乗り合わせの可 | string | `"可"` / `"不可"` |
| 6 | 乗り合わせの希望人数 | string | `"1"` |
| 7 | 配車メモ（管理者記入） | string | `"Aさん車"` |
| 8 | 備考 | string | `"16時には帰宅"` |

### Sheets 構成

```
スプレッドシート
├── <イベント名1>         ← 回答データ
├── <イベント名2>
├── 【結果】<イベント名1>  ← 配車確定データ（6列）
└── 【結果】<イベント名2>
```

## ローディング状態

全ページ共通のスピナーヘルパー関数を定義:

```javascript
const spin = (cls = 'h-4 w-4') => `<svg class="animate-spin ${cls} inline-block align-middle mr-1" ...></svg>`;
```

| ページ | タイミング | 対象要素 |
|---|---|---|
| index.html | ページ読み込み | セレクト・送信ボタン無効化、「読み込み中...」オプション表示 |
| index.html | 送信中 | ボタンにスピナー＋「送信中...」 |
| admin.html | ページ読み込み / loadEventList | イベント一覧エリアにスピナー表示 |
| admin.html | イベント作成中 | 作成ボタンにスピナー＋「作成中...」 |
| admin.html | イベント削除中 | 削除ボタンにスピナー＋「削除中」 |
| view.html | ページ読み込み | セレクト・読込ボタン無効化 |
| view.html | データ読み込み中 | 読込ボタンにスピナー、テーブルにローディング行表示 |
| view.html | 保存中 | 保存ボタンにスピナー＋「保存中...」 |
